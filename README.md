# This repository has moved

On 2026-09-11 `lolly-tools` was folded into the main Lolly repository and archived. Its content now lives at:

    https://github.com/lolly-tools/lolly/tree/main/community

The last commit imported from here was `023072ba6cc71c9cf68b0c6b80d48141dd5b1e17`. Every commit of this repository's history was carried across with `git subtree add`, so `git log --all --full-history -- <file>` in the main repository finds it; a bundle of this repository as it stood on that day is kept by the maintainer.

This repository stays public and read-only so that existing clone URLs, issue links and blame permalinks keep resolving. Please open new issues and pull requests on https://github.com/lolly-tools/lolly.

Tool authors: open pull requests against `lolly-tools/lolly` under `community/<tool-id>/`. The authoring guide is at https://lolly.tools/info/build/authoring-tools.html.
