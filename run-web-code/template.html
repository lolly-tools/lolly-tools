Run Web Code

Paste HTML, CSS and JavaScript — say, a snippet an AI assistant handed you — and see it run instantly.

  • Private & offline. Your code runs in a locked-down sandbox right here in your browser. Nothing is uploaded, and it works with no connection.
  • Isolated. The preview can't reach your saved work, this app, or your other tabs — it runs on its own throwaway origin.
  • Frameworks. Switch the JS language to JSX, TypeScript or TSX and paste a component — it's transpiled and, for React, mounted into #root for you. React is bundled in, so it all works offline. Name your component App for auto-mounting, or render it yourself.
  • External libraries. To keep things private and offline, scripts and styles loaded from the web are blocked by default. When your code references one, you can choose to fetch & inline it — trusted sources like Google Fonts work out of the box; others may be blocked by the app's security policy.
